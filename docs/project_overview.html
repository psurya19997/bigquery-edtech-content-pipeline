Learning Content Pulse

Indian-language learning content: supply, demand & performance. An automated GCP pipeline built on public data only.

Goal: find where Indian-language learners are underserved (lots of use, too little content) and what makes educational content actually get used. Then turn that into a ranked list of "what to localize next".
  • Decision it supports: which language × grade × subject × state board to create or translate content for first.
  • Skills it demonstrates: APIs + Google Sheets → BigQuery (ELT) → dashboard, with data-quality checks, statistics and Git.
